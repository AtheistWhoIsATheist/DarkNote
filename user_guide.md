# Professor Nihil PKM Application - User Guide

## Overview

The Professor Nihil PKM (Personal Knowledge Management) Application is a powerful note-taking and philosophical exploration tool that combines markdown editing capabilities with an integrated AI philosopher chatbot. This application allows you to create, edit, and organize notes while engaging in deep philosophical conversations with Professor Nihil, the synthetic Arch-Sage of Nihiltheism.

## Key Features

### 1. Integrated Sidebar Chatbot
- Professor Nihil AI Philosopher accessible from the right sidebar
- Four philosophical modes: Recursive-Dialectic, Ontological-Collapse, Apophatic-Synthesis, and Mythopoetic-Logic
- Expandable/collapsible for space efficiency

### 2. Markdown Editor with Preview
- Clean, distraction-free writing environment
- Live markdown preview with toggle button
- Formatting toolbar for common markdown elements

### 3. AI Feature Dropdown Menu
- Accessible from the left sidebar
- Six powerful AI features:
  - **Summarize**: Create concise summaries of your notes
  - **Expand**: Elaborate and develop your ideas further
  - **Analyze**: Examine structure, themes, and patterns
  - **Deep Research**: Explore philosophical depths and connections
  - **Rewrite**: Rephrase content with improved clarity
  - **Brainstorm**: Generate related ideas and concepts

### 4. Efficient Layout
- Three-panel design (left sidebar, main content, right sidebar)
- Responsive design for different screen sizes
- Keyboard shortcuts for common actions

## Getting Started

1. **Open the Application**: Open the `optimized_index.html` file in any modern web browser.

2. **Create a New Note**:
   - Click the "New Note" button in the left sidebar
   - Enter a title and optional tags
   - Start writing in the markdown editor

3. **Format Your Note**:
   - Use the formatting toolbar buttons or keyboard shortcuts
   - Toggle the preview panel to see the formatted result

4. **Save Your Note**:
   - Click the "Save" button or use Ctrl+S
   - Your note will be stored in the browser's local storage

5. **Use AI Features**:
   - Click on "AI Features" in the left sidebar
   - Select the desired feature from the dropdown
   - The AI will process your note content and display results in the right sidebar

6. **Engage with Professor Nihil**:
   - Toggle the AI sidebar if not already visible
   - Select a philosophical mode from the dropdown
   - Type your question in the input field and send
   - Engage in philosophical conversation

## Keyboard Shortcuts

- **Ctrl+S**: Save note
- **Alt+P**: Toggle preview panel
- **Alt+A**: Toggle AI sidebar
- **Ctrl+B**: Bold text
- **Ctrl+I**: Italic text

## Technical Details

This application is built with HTML, CSS, and JavaScript, and runs entirely in the browser. All notes are stored in your browser's local storage, ensuring privacy and offline access. The AI features are simulated in this demonstration version but can be connected to actual AI services like OpenAI's GPT models for production use.

## Customization

The application can be customized by modifying the HTML, CSS, and JavaScript code. Key areas for customization include:

- Color scheme in the CSS variables
- AI response generation in the JavaScript functions
- Additional markdown formatting options
- New AI features in the dropdown menu
