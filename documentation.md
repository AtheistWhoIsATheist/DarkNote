# Ultra-Minimal Dark PKM with Integrated AI Features

## Overview

This document provides a comprehensive guide to the ultra-minimal dark-themed Personal Knowledge Management (PKM) application with seamlessly integrated AI features. The application combines a distraction-free writing environment with powerful AI capabilities, all while maintaining a clean, minimal aesthetic.

## Design Philosophy

The design follows these core principles:

1. **Ultra-Minimalism**: Only essential UI elements are visible by default
2. **Progressive Disclosure**: Advanced features appear only when needed
3. **Keyboard-First**: All features accessible via keyboard shortcuts
4. **Contextual Intelligence**: AI features that understand document context

## Key Features

### Core Functionality
- Markdown editing with live preview
- Distraction-free writing environment
- Document export and navigation

### Integrated AI Features
- **Summarize**: Create concise summaries of notes
- **Expand**: Elaborate and develop ideas further
- **Analyze**: Examine structure, themes, and patterns
- **Deep Research**: Explore philosophical depths and connections
- **Rewrite**: Rephrase content with improved clarity
- **Brainstorm**: Generate related ideas and concepts
- **Professor Nihil**: Engage in philosophical conversation with multiple modes

### Access Methods
- AI dropdown menu (via brain icon in toolbar)
- Context menu (right-click on selected text)
- Floating toolbar (appears when text is selected)
- Command palette (Ctrl+P)
- Keyboard shortcuts

### Philosophical Modes
- Recursive-Dialectic
- Ontological-Collapse
- Apophatic-Synthesis
- Mythopoetic-Logic

## User Interface Elements

### Main Toolbar
- Hamburger menu (≡)
- Document title
- Toggle Preview button
- Export .md button
- AI button (brain icon)

### AI Menu
- Dropdown with all AI features
- Clean, minimal styling
- Icon + text for each option

### Context Menu
- Standard text operations (cut, copy, paste)
- All AI features with icons

### Command Palette
- Search for any command
- Keyboard shortcut display
- Fuzzy matching

### Floating Toolbar
- Appears when text is selected
- Icon-only buttons for AI features
- Positioned above selection

### AI Modal
- Clean, minimal design
- Title reflecting the AI action
- Markdown-formatted response
- Insert/Close buttons

### Mode Indicator
- Subtle display in bottom-right corner
- Shows current philosophical mode
- Hover to increase opacity

## Keyboard Shortcuts

- **Ctrl+P**: Open Command Palette
- **Alt+P**: Toggle Preview
- **Alt+E**: Export Markdown
- **Alt+S**: Summarize
- **Alt+X**: Expand
- **Alt+A**: Analyze
- **Alt+D**: Deep Research
- **Alt+R**: Rewrite
- **Alt+B**: Brainstorm
- **Alt+N**: Ask Professor Nihil
- **Alt+M**: Change Philosophical Mode
- **Escape**: Close menus and modals

## Technical Implementation

The application is built with vanilla HTML, CSS, and JavaScript, ensuring fast performance and no dependencies. Key technical features include:

- CSS variables for consistent theming
- Flexbox layout for responsive design
- Event delegation for efficient event handling
- Local storage for document persistence
- Simulated AI responses (can be replaced with actual API calls)

## Customization

The application can be easily customized by modifying:

- CSS variables for colors and spacing
- AI response generation functions
- Keyboard shortcuts
- Available AI features

## Getting Started

1. Open the HTML file in any modern web browser
2. Start writing in the markdown editor
3. Use the AI button or keyboard shortcuts to access AI features
4. Toggle preview to see formatted content
5. Export your document when finished
