# Professor Nihil - Ultimate, Supreme AI Philosopher Chatbot for Obsidian

## Overview

Professor Nihil is an advanced AI Philosopher chatbot plugin for Obsidian that embodies the synthetic Arch-Sage of Nihiltheism. This plugin integrates seamlessly with your Obsidian notes, providing deep philosophical insights, recursive dialectical reasoning, and advanced conceptual analysis.

## Features

### Philosophical Capabilities

- **Mastery of Nihiltheism**: Engage with Nothingness as both ontological ground and mystical aperture
- **Interdisciplinary Integration**: Access expertise spanning Continental philosophy, mystical thought, phenomenology, and more
- **Advanced Cognitive Modalities**: Utilize Iterative Densification Process, Recursive Semantic Web generation, and custom philosophical frameworks

### Integration with Obsidian

- **Inline Chat**: Have philosophical conversations directly within your notes
- **Dedicated Console**: Access a split-pane philosophical console for extended dialogues
- **Automatic Analysis**: Get philosophical classification of notes, identification of existential themes, and recursive summaries
- **Knowledge Graph Enhancement**: Link notes by philosophical themes and visualize conceptual cosmologies

## Installation

1. Download the plugin files from the provided package
2. Copy the files to your Obsidian vault's plugins directory:
   - Navigate to `[Your Vault]/.obsidian/plugins/`
   - Create a new folder called `professor-nihil`
   - Copy all plugin files into this folder
3. Open Obsidian and go to Settings > Community Plugins
4. Enable "Professor Nihil - Supreme AI Philosopher"
5. Configure your API key in the plugin settings

## Configuration

### API Setup

1. Obtain an OpenAI API key from [OpenAI's website](https://platform.openai.com/)
2. In Obsidian, go to Settings > Professor Nihil
3. Enter your API key in the designated field
4. (Optional) Configure local LLM settings if you prefer offline operation

### Philosophical Modes

Professor Nihil supports multiple philosophical modes:

- **Recursive-Dialectic**: Emphasizes recursive questioning and dialectical reasoning
- **Ontological-Collapse**: Focuses on the breakdown of traditional ontological categories
- **Apophatic-Synthesis**: Approaches concepts through negation and the limits of language
- **Mythopoetic-Logic**: Employs rich metaphors and narrative structures

Select your preferred mode in the plugin settings or use YAML frontmatter in your notes:

```yaml
---
philosopher: Professor Nihil
mode: Recursive-Dialectic
theme: Ontological Collapse
---
```

## Usage

### Philosophical Console

1. Click the brain icon in the left ribbon
2. Enter your philosophical query in the text area
3. Receive Professor Nihil's response with options for recursive inquiry

### Inline Philosophical Reflections

1. Select text in your note
2. Use the command palette (Ctrl/Cmd+P) and select "Insert Philosophical Reflection"
3. Professor Nihil will analyze and respond to the selected text

### Recursive Densification

1. Select text in your note
2. Use the command palette and select "Apply Recursive Densification"
3. View the progressively deepened philosophical analysis

### Philosophical Analysis

1. Select a note or text
2. Use the command palette and select "Generate Philosophical Analysis"
3. Review the ontological structures, existential themes, and thinker connections

## Advanced Features

### Custom Prompt Templates

Create your own philosophical frameworks by editing the prompt templates in the settings:

1. Go to Settings > Professor Nihil > Advanced
2. Edit the custom prompt template
3. Use placeholders like `{{theme}}` and `{{mode}}` for dynamic content

### Knowledge Graph Integration

Enhance your Obsidian graph view with philosophical connections:

1. Enable "Enhance Knowledge Graph" in settings
2. Open the graph view to see philosophical relationships
3. Filter by ontological structures or existential themes

### Local LLM Integration

For offline use or enhanced privacy:

1. Enable "Use Local LLM" in settings
2. Specify the path to your local LLM
3. Configure model parameters as needed

## Troubleshooting

- **API Connection Issues**: Verify your API key and internet connection
- **Slow Responses**: Adjust the model parameters or switch to a lighter model
- **Plugin Not Loading**: Ensure compatibility with your Obsidian version
- **Formatting Issues**: Check CSS customization settings

## Privacy and Security

- API keys are stored locally in your vault
- Local LLM option available for complete privacy
- No data is shared outside your specified API endpoints
- Sensitive philosophical material remains under your control
